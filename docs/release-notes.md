音序 v0.7.1 将错题复习带到 Windows 免安装包和轻量网页包。主线 L0–L2 的课内题答错后会排到次日，首页会显示到期题量。

- 每次复习答对后，间隔依次延长到 3、7、14、30 天。再次答错时，次日继续复习。
- 错题安排随学习记录导出。可以把网页版导出的备份导入离线版，也可以导入旧版 v1、v2 的学习记录。
- 全站有 203 条课程路线、1,208 节中文课程。音乐素养主线和首批五条乐器线均覆盖 L0–L5。

Windows 10 / 11 的 Intel / AMD 64 位用户请下载 `yinxu-v0.7.1-windows-x64.zip`，完整解压后双击 `start.bat`。免安装包自带运行环境，打开后可离线学习。`yinxu-v0.7.1-web.zip` 供静态部署或使用本机 Node.js 的用户，`SHA256SUMS.txt` 用于校验两个 ZIP。

升级前，可在旧版“学习记录”导出 JSON 备份。关闭旧启动器后解压新版。使用同一浏览器和本地端口时，现有记录会继续可用；换浏览器、端口或在线／离线版本时，请在新版导入备份。
