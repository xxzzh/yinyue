新增 Windows 64 位免安装版，下载并解压后双击即可使用，无需另装 Node.js、Python 或 npm。

- **普通 Windows 用户：下载 `yinxu-v0.1.2-windows-x64.zip`，完整解压，双击 `start.bat`。**
- 适用 Windows 10 / 11 的 Intel / AMD 64 位电脑；启动后自动打开默认浏览器。
- 保持启动窗口打开即可学习，关闭窗口或按 Ctrl+C 停止；解压后可离线使用。
- 默认本地网址为 `http://127.0.0.1:4173/`，端口占用时自动切换，以启动窗口显示的网址为准。
- 内置 Node.js v24.22.2，原始官方压缩包经 SHA-256 验证，保留运行环境许可证与来源。

已验证中文及空格路径、PATH 中没有系统 Node.js 的启动情况，以及网页资源完整性。自动发布会先在 Windows 上验证实际 ZIP 中的启动器。

**直接使用：https://xxzzh.github.io/yinyue/**

在线版无需注册或登录。学习进度保存在各自浏览器，可导出与导入备份。

包含屏幕与电脑键盘钢琴、可选 MIDI 输入、吉他指板及五种开放和弦、四种音程听辨、40–180 BPM 节拍器、拍速估算、音阶跟唱和 MusicXML 五线谱。

`yinxu-v0.1.2-web.zip` 是给开发者的轻量网页包，本地运行需要 Node.js 18+，也可部署到静态服务器。普通 Windows 用户请选择上面的 `windows-x64.zip`。

在线版与本地版、不同浏览器或端口的进度各自独立，可通过“学习记录”的导出与导入迁移。升级时先关闭旧版启动窗口，再运行新版。

`SHA256SUMS.txt` 用于核对 ZIP 文件完整性。源码 ZIP / TAR.GZ 由 GitHub 自动提供，适合开发者二次开发。

本版本不包含账号、云同步、教师后台或麦克风演奏评分。吉他与钢琴使用合成参考音色；MIDI 输入需要浏览器支持及设备授权。
