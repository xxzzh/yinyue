- 新增世界乐器主导航、首页入口、中英文及别名搜索、类别与地域筛选、分页和手机布局。
- 保留已有课程 ID、练习工具和学习进度格式。

**在线使用：[世界乐器专区](https://xxzzh.github.io/yinyue/#/world) · [中国乐器专区](https://xxzzh.github.io/yinyue/#/traditional)**，无需登录。

**Windows 用户下载 `yinxu-v0.4.0-windows-x64.zip`，完整解压后双击 `start.bat`。**
自带运行环境，适用 Windows 10 / 11 的 Intel / AMD 64 位电脑，无需安装 Node.js、Python 或 npm。启动窗口保持打开即可学习；图片、文字、练习任务与测验支持离线使用。

`yinxu-v0.4.0-web.zip` 为轻量网页包，适合静态部署或已安装 Node.js 的开发者。`SHA256SUMS.txt` 可校验两个 ZIP。

本版覆盖常见与部分地域代表乐器，未穷尽世界所有变体。新增课程属于认识与启蒙内容，尚未内置真实音视频，不等于完整演奏教程。延伸资料需要联网，部分资料为外语。原创示意不作为尺寸、指法、精确弦数或制器依据；第三方照片继续按各自许可使用。

升级前可在“学习记录”导出备份。在线版、本地版及不同浏览器、端口的进度各自独立，可导入备份合并。
