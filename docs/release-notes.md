音序 v0.7.0 带来从启蒙到结业的分级学习路线。全站有 203 条课程路线、1,208 节中文课程，课程正文和练习可离线使用。

- 音乐素养主线与钢琴、吉他、声乐、古筝、口笛五条乐器线均覆盖 L0–L5。主线支持定级测验和阶段解锁。
- 主线 L5 通过独奏会录音、原创作品的乐谱与录音、作品分析三项自评结业。五条乐器线各有独立的结业关卡。成果文件由学习者保留。
- 新增或扩充简谱与五线谱对照、吉他六线谱、节奏和旋律听写、视奏、四部和声、音准及录音回放工具。
- 学习记录支持原有 v1 备份和新版 v2 备份。新版记录包含阶段测验结果、定级和作品集自评。

Windows 10 / 11 的 Intel / AMD 64 位用户请下载 `yinxu-v0.7.0-windows-x64.zip`，完整解压后双击 `start.bat`。免安装包自带运行环境，打开后可离线学习。`yinxu-v0.7.0-web.zip` 供静态部署或使用本机 Node.js 的用户，`SHA256SUMS.txt` 用于校验两个 ZIP。

升级前，可在旧版“学习记录”导出 JSON 备份。关闭旧启动器后解压新版。使用同一浏览器和本地端口时，现有记录会继续可用；换浏览器、端口或在线／离线版本时，请在新版导入备份。
