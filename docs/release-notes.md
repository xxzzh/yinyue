修复浏览器 100% 缩放时，左侧导航底部内容显示不全的问题。

- 根据窗口高度收紧侧栏间距，常规桌面窗口可完整显示学习路线、寄语和每日目标。
- 特别矮的窗口支持侧栏独立滚动，所有导航入口均可通过鼠标、触摸或键盘访问。
- 同时适配窄屏图标导航和手机展开菜单。

已在 1280×900、1280×720、1280×600、1280×480、900×600、390×640 和 740×360 的浏览器窗口中验证。

**直接使用：https://xxzzh.github.io/yinyue/**

在线版无需注册或登录。学习进度保存在各自浏览器，可导出与导入备份。

包含屏幕与电脑键盘钢琴、可选 MIDI 输入、吉他指板及五种开放和弦、四种音程听辨、40–180 BPM 节拍器、拍速估算、音阶跟唱和 MusicXML 五线谱。

下载 `yinxu-v0.1.1-web.zip` 可获得已构建网页，解压后无需安装项目依赖。安装 Node.js 18+ 后，Windows 双击 `start.bat`，其他系统运行 `node serve.mjs`，按提示打开本地网址。也可将静态文件部署到自己的服务器。

`SHA256SUMS.txt` 用于核对 ZIP 文件完整性。源码 ZIP / TAR.GZ 由 GitHub 自动提供，适合开发者二次开发。

本版本不包含账号、云同步、教师后台或麦克风演奏评分。吉他与钢琴使用合成参考音色；MIDI 输入需要浏览器支持及设备授权。
