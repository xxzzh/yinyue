新增“选适合的乐器”，并补齐本轮核对的54种遗漏：全站现有200种乐器、202条学习路线、618节基础与启蒙课。

- 每种乐器分别提供典型音色、声音成因、表现特色、入门难点、准备条件与选学标签。
- 可按音色偏好、原声音量/耳机方案、便携与空间、入门方式、图鉴和类别组合筛选；最多三件并排比较。
- 新增12种中国乐器和42种世界乐器，包含马骨胡、口笛、灼吧、方响、电吉他、古典吉他、羽管键琴、英国管、次中音号和多种地域乐器。
- 中国及世界专区各100种；新增54种各有三课、原创示意、练习任务和测验，保留既有课程及进度格式。
- 内置16种乐器的真实录音节选，来自按CC0授权的VSCO 2 CE，标注独奏/声部、来源及处理方式，离线可播放。
- 未收录真实录音的乐器明确提供文字音色与外部资料入口，不把合成参考音当实录。
- 新增“为什么乐器声音不同”的振动、起音衰减与共鸣说明；图鉴卡片也可先看音色标签。
- 192幅配图和完整音频来源页随离线包提供，优化手机筛选与横向对比。

在线使用：[选乐器](https://xxzzh.github.io/yinyue/#/choose) · [中国乐器](https://xxzzh.github.io/yinyue/#/traditional) · [世界乐器](https://xxzzh.github.io/yinyue/#/world)。无需登录。

Windows 用户下载 `yinxu-v0.5.0-windows-x64.zip`，完整解压后双击 `start.bat`，自带运行环境，无需安装Node.js、Python或npm。适用Windows 10/11的Intel/AMD 64位电脑。

`yinxu-v0.5.0-web.zip` 为静态网页包，适合部署或已安装Node.js的开发者。`SHA256SUMS.txt`用于校验。

音色会随形制、音区、力度、奏法与录音环境变化；内置样本音高、力度和独奏/合奏人数不统一，不宜仅凭响度比较。选学条件属于一般参考，不代表实时库存、价格或精通速度。历史复原乐器没有可代表所有年代的唯一“标准古代原声”。本版未穷尽所有地域变体；新路线仍以认识与启蒙为主，外部资料需联网。

升级前可导出学习记录备份；在线与本地、不同浏览器和端口的进度分别保存，可导入合并。
