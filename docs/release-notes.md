乐器图鉴换上真实照片，每件乐器新增“使用说明与演奏指南”，网页加载更快。

- 118种乐器由原创外形示意改为真实照片（钢琴、吉他、中提琴、大提琴、低音提琴、竖琴、各类管乐与打击乐等），均来自 Wikimedia Commons 中授权明确的图片，作者与授权见图片署名页。16种暂无可再分发照片的地方乐器继续使用标明“外形示意”的原创图。
- 200种乐器的详情页新增“使用说明与演奏指南”：Fender、Yamaha 等厂商的使用手册和演奏方法页，课程原有的专题资料，以及维基百科条目。外部资料需联网。
- 网页按需加载各专区与练习工具，首屏脚本由约828KB降至约600KB；网站更新后仍开着的旧页面会自动刷新一次，加载失败时显示“刷新页面”按钮。
- 16段真实录音改为MP3，音频总量由6.5MB降至1.3MB，音色与时长不变。
- 构建工具与依赖升级到新版本（Vite 8、TypeScript 6、OpenSheetMusicDisplay 2 等），并加入代码检查与统一格式。
- 保留原有618节课程、200种乐器、对比功能与学习进度；旧版导出的学习记录可直接导入。

在线使用：[打开音序](https://xxzzh.github.io/yinyue/)。无需登录。

Windows用户下载 `yinxu-v0.6.0-windows-x64.zip`，完整解压后双击 `start.bat`。自带运行环境，无需安装Node.js、Python或npm，适用Windows 10/11的Intel/AMD 64位电脑。

`yinxu-v0.6.0-web.zip` 为静态网页包，适合部署或已安装Node.js的开发者。`SHA256SUMS.txt`用于校验。图片、已内置录音、正文与练习支持离线；外部资料需联网。
