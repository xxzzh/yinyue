为所有目录分页增加页码输入框：输入目标页码后点击“跳转”或按回车，可直接前往指定页面。

- 统一应用于全部课程、中国乐器、世界乐器和选乐器页面。
- 只接受当前范围内的整数页码；空值、小数、零和超出范围的值由输入框提示纠正。
- 翻页或筛选改变总页数时，输入框同步到实际页码；单页结果继续隐藏分页。
- 手机端跳转输入独立成行，保持上一页、当前页和下一页可用。
- 保留原有200种乐器、特色说明、对比功能、16段真实录音与学习进度。

在线使用：[选乐器](https://xxzzh.github.io/yinyue/#/choose)。无需登录。

Windows用户下载 `yinxu-v0.5.1-windows-x64.zip`，完整解压后双击 `start.bat`。自带运行环境，无需安装Node.js、Python或npm，适用Windows 10/11的Intel/AMD 64位电脑。

`yinxu-v0.5.1-web.zip` 为静态网页包，适合部署或已安装Node.js的开发者。`SHA256SUMS.txt`用于校验。图片、已内置录音、正文与练习支持离线；外部资料需联网。
