为中国传统乐器图鉴补齐图片：84 种乐器现在都能看图认识外形。

- 新增 64 张实物照片、2 幅历史图像及 18 幅原创结构示意，清楚标注图片种类与代表形制。
- 图鉴卡片、课程首页和课文均展示配图，支持放大观察、查看作者、来源与授权。
- 图片随网站和离线包一起提供，无需联网加载；新增完整的离线图片署名页。
- 优化手机端的图文排列，图片完整等比展示，细长乐器不裁切。
- Windows 本地服务器补齐常见图片格式的响应类型，发布验证逐张检查全部图片。
- 原有课程、练习和学习进度继续保留。

**在线使用：[中国传统乐器图鉴](https://xxzzh.github.io/yinyue/#/traditional)**，无需登录。

**Windows 用户下载 `yinxu-v0.3.1-windows-x64.zip`，完整解压后双击 `start.bat`。**
自带运行环境，适用 Windows 10 / 11 的 Intel / AMD 64 位电脑，无需安装 Node.js、Python 或 npm。启动窗口保持打开即可学习；图片、文字、练习任务与测验支持离线使用。

`yinxu-v0.3.1-web.zip` 为轻量网页包，适合静态部署或已安装 Node.js 的开发者。`SHA256SUMS.txt` 可校验两个 ZIP。

图片展示代表性形制，无法涵盖所有地域变体；结构示意不作为尺寸、指法或制器依据。新增课程尚未内置真实音视频，延伸资料及图源链接需要联网。第三方图片分别遵循署名页所列许可。

升级前可在“学习记录”导出备份。在线版、本地版及不同浏览器、端口的进度各自独立，可导入备份合并。
