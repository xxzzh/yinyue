新增“中国传统乐器”学习专区，覆盖 84 种代表乐器、254 节认识与入门课。

- 新增 82 条三课路线：形制认识、发声与起步、听赏与练习计划；包括古琴、琵琶、阮、柳琴、笛箫、笙、唢呐、各类胡琴、民族与地方乐器及部分历史乐器。
- 古筝、二胡保留原有各四课、参考音工具和学习进度。全站现有 94 条路线、294 节课。
- 支持类别、地域、名称、拼音、别名与相关形制查找；目录分页，首页与左侧导航提供专区入口。
- 新增三步观察任务、自主练习记录、每课测验及延伸资料；说明同名异器、历史复原与地方定弦的区别。
- 适配桌面与手机，保留侧栏独立滚动，旧版学习记录和备份可继续使用。

**在线使用：[中国传统乐器专区](https://xxzzh.github.io/yinyue/#/traditional)**，无需登录。

本版覆盖常见及部分地方、民族、历史乐器，并非全部地域变体的穷尽名录；新路线属于认知与启蒙内容，未提供每件乐器的完整专业演奏课程。新课程暂未内置真实录音或视频，延伸资料及部分示范需要联网。

**Windows 用户下载 `yinxu-v0.3.0-windows-x64.zip`，完整解压后双击 `start.bat`。**
自带运行环境，无需安装 Node.js、Python 或 npm。适用 Windows 10 / 11 的 Intel / AMD 64 位电脑。启动窗口保持打开即可学习；文字、练习任务与测验支持离线使用。

`yinxu-v0.3.0-web.zip` 为轻量网页包，适合静态部署或已安装 Node.js 的开发者。`SHA256SUMS.txt` 可校验两个 ZIP。

升级前可在“学习记录”导出备份。在线版、本地版及不同浏览器、端口的进度各自独立，可导入备份合并。
