# 分级学习大纲（草案 v0.1）

目标：让完全零基础的学习者，沿着一条清楚的路线，从“听见拍子”一路学到能独立演奏、分析与创作。本文件是课程设计依据，先定结构与课程清单，再分批写课和改代码。

> 状态：M1（路线骨架）已实现，课程按里程碑陆续补齐。课程标题是工作标题，写课时可以调整；课程总数和阶段划分确认后再动数据模型。

## 1. 设计原则

1. **一条主线，多条乐器线。** 所有人共用“音乐素养主线”（节奏、读谱、乐理、练耳视唱、创作、赏析）；乐器线按自己选的乐器走。现有 200 件乐器的认识课归入“乐器百科”，作为赏析与选乐器的支线，不再计为学习路线。
2. **用“能做到什么”定义阶段。** 每个阶段先写出可检查的能力描述，课程只是达到这些能力的手段。
3. **先听后看，先唱后写。** 新概念先从听、唱、拍开始，再给符号和名称。
4. **螺旋上升。** 同一主题（如音程、和弦）在多个阶段反复出现，每次加深一层。
5. **掌握后再往上。** 每个单元有小测，每个阶段有阶段测验；通过后解锁下一阶段。有基础的学习者可以通过定级测验直接跳级。
6. **诚实标注边界。** 网站能自动判定的（乐理题、听辨、节奏点击、MIDI 音高）就自动判定；不能判定的（音色、姿势、触键、表现）用录音回放加自评清单，并明确建议找老师当面指导。

## 5. 乐器线

### 5.1 通用模板

所有乐器线都按同一模板分级，便于以后批量扩展。乐器线第 k 阶段要求：乐器线 L(k−1) 已通过，**且**主线 L(k−1) 已通过。主线可以比乐器线走得快，反过来不行，避免“会弹不会读”。

| 阶段 | 节数 | 每阶段包含                                                                                     |
| ---- | ---- | ---------------------------------------------------------------------------------------------- |
| L0   | 4    | 认识乐器、姿势与持琴、第一个声音、保养与安全                                                    |
| L1   | 10   | 基本发声动作、第一个把位或手位、3–5 首短曲、每日练习清单                                        |
| L2   | 16   | 音阶与琶音（1 个八度起）、基本技法、6–8 首初级曲目、配合主线的视奏                              |
| L3   | 20   | 全部大小调音阶、进阶技法、练习曲、不同风格曲目、伴奏或合奏                                      |
| L4   | 20   | 高级技法、风格演奏、大型作品选段、录音与舞台                                                    |
| L5   | 15   | 独奏会曲目、演绎比较、个人风格、教学                                                            |

每件乐器约 85 节。每个阶段末有“演奏关卡”：MIDI 乐器自动核对音高与节奏，其他乐器以录音回放加自评清单完成，并提示找老师复核。

**逐节规划：** 首批五条乐器线的每一节课都已定好工作标题和顺序（现余 75 节待写，均为 L5，见 `src/instrument-lesson-plans.ts`），学习路线页逐条显示为“编写中”。写好一节，就把它的标题从规划中移出、把课程 ID 加入 `src/instrument-order.ts`；测试会检查每个阶段的已上线课程与规划标题加起来正好是模板节数，且每个阶段（L1 起）以关卡结尾。

## 6. 考核与掌握规则

- **题目：** 每节课 3–5 题，题型包括单选、听辨（音程、和弦、调式）、节奏点击、键盘或指板作答、谱面识读。答案位置随机；错误选项从**同一概念**的题库中抽取，不再借用其他乐器的描述；解析要说明为什么错，而不是重复正确答案。
- **单元小测：** 每个单元 8–10 题，正确率 80% 以上算通过。
- **阶段考核：** 主线 L0–L4 的阶段测验答对至少 80% 后解锁下一阶段。乐器线需要通过前一主线阶段并学完该乐器线的前一阶段，演奏或演唱关卡作为阶段末的一课。主线 L5 学完课程并完成作品集自评后结业。
- **定级测验：** 新用户可选择入口测验，从 L0 开始逐级出题，连续答错就停，推荐起点阶段；跳过的阶段标记为“定级通过”，不伪装成已学完。
- **复习：** 错题进入复习队列，按 1、3、7、14、30 天间隔再次出现；首页“今日任务”从“下一课 + 到期复习 + 当前乐器练习”中生成，不再固定写死。
- **掌握度：** 每个能力轴 0–100，按近期答题正确率计算，长时间不练会逐渐下降，用于推荐补弱。

## 7. 数据模型（M1 已实现）

课程本身（`Lesson`、`Course`）没有改动；分级信息单独放在路线数据里，用 `lesson.id` 引用现有课程。

- `src/curriculum.ts`（随首屏加载）：`Stage`、`Skill`、`LineId` 类型；六个阶段的目标与参考水平；主线和五条乐器线的单元 `Unit`。单元的 `items` 按顺序列出已上线课程 `{ lesson: 'ear-3' }` 和规划中的课程 `{ plan: '标题' }`；乐器线用 `extraPlanned` 记录还没定标题的节数。这里也有解锁规则 `stagePassed` / `stageUnlocked`、推荐下一步 `nextStep`，以及只含编号的阶段测验索引 `stageTestIndex`。
- `src/curriculum-content.ts`（只随学习路线页加载）：阶段测验题 `stageTests` 与各乐器的阶段技术、曲目方向 `instrumentPlans`。
- 解锁规则：主线第 k 阶段需要通过 L(k−1) 阶段测验，或定级测验已通过前序阶段。乐器线第 k 阶段需要乐器线 L(k−1) 和主线 L(k−1) 都已通过；乐器线以学完该阶段已上线的全部课程算作通过。解锁只约束学习路线的推荐和入口，目录页的课程仍可自由打开。
- 进度 `version: 2`：在 v1 基础上增加 `passedTests`（如 `core-l0`）、`placement`（`{ stage, date }`，stage 表示定级越过的阶段数）和 `instrument`（我的乐器）。存储键仍是 `yinxu.progress.v1`，读取 v1 时就地升级；导入备份时合并通过记录，定级取较高者，“我的乐器”保留当前值。旧版网站读到 v2 记录会提示版本不支持，并保留原记录的恢复副本。
- L5 自评保存在 `portfolio`，旧记录读取时默认为空。导入备份合并已勾选的成果。按能力轴的掌握度与错题复习队列仍在规划中。
- **新课程 ID：** 主线用 `{能力}{阶段}-{两位序号}`，如 `nt1-07`；乐器线用 `{乐器}-l{阶段}-{两位序号}`，如 `piano-l2-03`。现有 ID 原样保留。
- **内容存放（待决定）：** 主线新课可改用一课一个 Markdown 文件（frontmatter 写阶段、能力、先修和题目），构建时校验并生成索引。
- **按需加载（已完成）：** 首屏只带课程目录索引（`npm run index` 生成），课程正文在打开课程时加载；详见 architecture.md 的“按需加载”。
