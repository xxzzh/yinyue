# 中国传统乐器：收录与学习说明

本版共 100 个乐器入口，含常见民乐、各民族与地方代表乐器，以及部分历史乐器。相关大小形制及别名合并检索，不把每个别名重复计数。本目录不是所有地方变体的穷尽清单。

提供 98 条三课认知与启蒙路线，另保留古筝、二胡各四课，共 302 节传统乐器课。新路线提供结构、发声、起步任务、听赏指引、小结与测验，不宣称提供每件乐器完整的演奏体系。

文字与练习为原创；资料用于核对基本事实和延伸阅读，未复制第三方音视频、图片或教材章节。新路线无内置真实音视频；延伸网页及部分示范需要联网。公开文本、观察任务、测验可随发布包离线使用。

地域标签仅供导览，既不限定归属也不声明唯一源头。演奏方式分类与材料、发声体分类分开：扬琴和筑为击弦，口弦为簧舌体鸣，铜鼓与蒙皮鼓不同。侗族牛腿琴和其他民族同名形制分别说明。历史复原演奏不称作古代原声。
