# 乐器照片补齐核查（2026-11-04）

本轮从待办的16种乐器出发，检索 Commons 文件和分类、允许再分发的 Flickr 照片，以及馆藏、非遗和演奏机构资料。除中文名、繁体名、拼音和英文别名外，也检查了博物馆编号照片、地方演出与乐团合奏图集。未找到不代表世界上不存在合格照片；这里只记录本轮可核验的结果。不把网页文字的 CC 许可当作照片许可。

## 继续补齐所需素材

需要作者或馆方提供可核验的 CC0、公有领域、CC BY 或 CC BY-SA 实物照片。自行拍摄时保留拍摄者、日期、地点及器物展签；授权应覆盖公开代码仓库、网站、离线包和再次分发。收到候选后仍须核对具体形制，随后更新账本并执行同步脚本。仅限平台浏览、含 NC／ND 的图片及未确认来源的网络转载不进入发布目录。
