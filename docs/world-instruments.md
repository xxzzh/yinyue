# 世界乐器收录与学习说明

v0.4.0 新增 50 种世界乐器，连同原有钢琴、吉他、尤克里里、电贝斯、小提琴、架子鼓、长笛和中音萨克斯，共 58 种、182 节课。中国乐器另设 88 种、266 节课的专区；另有乐理与听觉共 8 节。全站共 146 种乐器、148 条学习路线、456 节课。

本目录展示常见乐器与部分地域代表传统，未穷尽全部民族乐器、地方变体、历史复原和现代实验乐器。别名和相关形制用于搜索，不重复计数。安第斯排箫单列音乐语境，和中国排箫分别给出观察任务；“非洲鼓”等宽泛俗称仅作为搜索入口，不把某一种乐器写成整片地区所有鼓的代表。

新增每种乐器提供三课：结构与区别、发声与第一步、带着问题听赏。任务可通过图文观察、轻拍节奏和有注明来源的外部示范完成，不要求先购买乐器。新路线没有真实音色录音、演奏评分或完整的分级演奏教材；实物定弦、气息、持奏与调音需匹配具体形制。离线包包含图文、示意与测验，外部资料和演奏示范需联网。

配图为原创外形示意，明确标注，不充当实物照片、精确尺寸或指法表。部分同族乐器共用简化结构，以课程文字区分尺寸与音区；不据示意中的绘制数量推断实物弦数。许可与维护方法见 [配图说明](instrument-images.md)。

地域标签仅用于导览，不断言唯一源头、民族归属或只在一个地区使用。原有八种常见乐器归入“跨地区与现代”，避免误读为唯一产地。卡林巴归在打击乐浏览组，但课程明确它属于拨奏体鸣乐器；贝林包归在弦乐浏览组，课程明确其实际动作为击弦；钢片琴通过键盘击打金属音板，不与钢琴击弦混同。
